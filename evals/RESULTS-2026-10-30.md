## Reading

- By the fixed criterion the context file is **not** a win: with it the runs cost the same (S14/S15) or about 20 % more (S16/S17), and the score is equal.
- The graders do not check whether the agent claims what a status code means without a source, which is what the context file is for. Equal scores say the agent found the same differences, not that it was equally careful. These scenarios do not measure that.
- The scenarios were written to favour the context file and it still did not reduce cost; the likely reason is the extra turns spent reading and citing it.
- Not measured: whether the context file saves tokens on a large schema where the agent would otherwise explore. That needs a bigger scenario.
